# 🧮 Calculadora em Python

Projeto desenvolvido durante meus estudos de Python, com o objetivo de praticar os fundamentos da linguagem através da construção de uma calculadora executada pelo terminal.

## 📌 Sobre o projeto

A aplicação permite que o usuário realize quatro operações matemáticas:

- Soma
- Subtração
- Multiplicação
- Divisão

Após realizar uma operação, o programa permite que o usuário escolha entre realizar uma nova operação ou encerrar a aplicação.

## ⚙️ Funcionalidades

- Menu interativo no terminal
- Soma de dois números
- Subtração de dois números
- Multiplicação de dois números
- Divisão de dois números
- Repetição das operações através de um loop
- Opção para encerrar o programa
- Limpeza do terminal entre as operações

## 🧠 Conceitos praticados

Durante o desenvolvimento do projeto, foram utilizados conceitos fundamentais de Python, como:

- Variáveis
- `input()` e `print()`
- Estruturas condicionais (`if`, `elif` e `else`)
- Estrutura de repetição (`while`)
- `break`
- Funções com `def`
- Parâmetros e argumentos
- `return`
- Operadores matemáticos
- Importação e utilização do módulo `os`

## ▶️ Como executar

É necessário ter o Python instalado na máquina.

Clone o repositório ou baixe os arquivos e execute:

```bash
python Calculadora.py
```

O programa será executado diretamente no terminal.
