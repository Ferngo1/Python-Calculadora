# 🧮 Calculadora em Python — Roadmap

Documento pessoal para registrar as futuras atualizações, funcionalidades desejadas e conceitos que pretendo aprender durante a evolução do projeto.

---

# 📍 Status atual

**Versão:** 1.0.0  
**Status:** 🟢 Funcional

A calculadora atualmente permite realizar operações básicas através do terminal:

- Soma
- Subtração
- Multiplicação
- Divisão
- Repetição de operações
- Encerramento do programa

---

# 🎯 Objetivo do projeto

Utilizar a calculadora como um projeto contínuo para aplicar os conceitos aprendidos durante meus estudos de Python.

A ideia não é apenas adicionar funcionalidades, mas utilizar cada atualização como uma oportunidade para aprender novos conceitos da linguagem.

**Objetivo:** tornar o programa mais resistente a entradas inválidas.

### Funcionalidades

- [ ] Impedir divisão por zero

- [ ] Validar a opção escolhida no menu

### Conceitos que preciso aprender

- [ ] `try`
